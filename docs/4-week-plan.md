# TriageLearn — Four-Week Delivery Plan

## Week 1 — Foundation

- PERN repository scaffold
- PostgreSQL schema and technical seed
- JWT cookie authentication
- STUDENT/FACULTY RBAC
- dashboard and scenario API
- reusable scenario entry shell
- architecture/ERD/API documentation

## Week 2 — Core gameplay P0

- reusable `ScenarioEngine`
- standard precautions
- patient arrival/info/interview
- vital-sign mini-games
- assessment findings
- ESI decision with under/overtriage feedback
- routing and critical-failure logic
- centralized XP ledger/service
- completion/feedback screen

## Week 3 — Progression and research

- mandatory 15-item pre-test
- tutorial flow
- timer + server-side duration validation
- deterministic deterioration stages
- retry/failure/lock rules
- five scenarios per tier
- configurable tier thresholds
- post-test
- top-10 leaderboard

## Week 4 — Faculty, security, QA, deployment

- faculty read-only dashboard
- student and scenario analytics
- pre/post comparison and research view
- validation/security hardening
- browser/device testing
- automated API/component tests
- 30-user load test
- deployment and demo rehearsal

## Priority discipline

P0 beats polish. Animations, sounds, badges, and advanced visualization are deferred until the engine and scoring are stable.
